# Background Remover V8 — Minimal AI UI

Minimal version of the Background Remover project.

- Supplied logo converted to transparent PNG
- Logo used in navbar and footer
- Purple/lavender multi-shade UI retained
- No unnecessary navigation/features/attributes
- One focused upload workflow
- Automatic AI background removal with rembg
- Transparent PNG output with original dimensions

Run:
python -m pip install -r requirements.txt
python app.py

Open http://127.0.0.1:5000
